### Hi, I'm Kaz Iwaki (@erurami)

I'm an undergraduate studying Information and Communications Engineering at Institute of Science Tokyo.

I like building things close to the metal — compilers, compression, bit-level I/O — and I'm currently interested in where neural networks meet physics simulation, and in AI agents that act on real personal context.

**Selected work**

- [first-compiler](https://github.com/erurami/first-compiler) — a small C compiler written from scratch: tokenizer → recursive descent parser → x86-64 codegen
- [huffman-coding-core](https://github.com/erurami/huffman-coding-core) — Huffman compression built fully from scratch in C++, with my own bit-level I/O library ([bitio](https://github.com/erurami/bitio)) and a custom file format
- [connect4-bot](https://github.com/erurami/connect4-bot) — Connect Four engine with minimax and alpha-beta pruning

**Languages**: C++ / C / Python / Rust / Lua
